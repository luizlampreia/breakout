🎮 Jogo Breakout em JavaScript
📖 Descrição

Projeto de desenvolvimento de jogo inspirado no clássico Breakout do Atari, com foco na aplicação de lógica de programação e conceitos fundamentais de desenvolvimento em JavaScript. O jogo foi construído utilizando estruturas condicionais, vetores e controle de fluxo para simular física básica e interatividade em tempo real.

🎯 Objetivo

Desenvolver um jogo interativo no navegador para aplicar conceitos de lógica de programação, incluindo controle de movimento, colisões, pontuação e estruturação de algoritmos.

⚙️ Tecnologias Utilizadas

JavaScript, HTML, Canvas (renderização gráfica)

🧠 Conceitos Aplicados
Estruturas condicionais (if/else)
Laços de repetição (for)
Vetores (arrays)
Controle de estado do jogo
Lógica de colisão
Manipulação de coordenadas (x, y)
🔍 Funcionamento do Jogo
🎮 Estrutura Inicial
Criação do canvas para renderização do jogo
Definição da posição inicial da bola
Configuração dos elementos principais (bola e barra)
🔄 Game Loop
Atualização contínua da posição dos elementos
Renderização em tempo real
Controle de eventos e movimentação
🎯 Movimentação
Barra controlada pelo jogador no eixo horizontal
Bola com movimento dinâmico no canvas
💥 Colisões
Colisão da bola com paredes laterais
Colisão com a barra do jogador
Colisão com blocos (destruição dos elementos)
🧱 Blocos
Implementação de múltiplos blocos utilizando vetores
Remoção dos blocos após colisão
Organização eficiente dos elementos na tela
🏆 Sistema de Pontuação
Incremento de pontuação a cada bloco destruído
Controle de pontuação máxima
Feedback ao jogador ao atingir o objetivo
❌ Condição de Game Over
Encerramento do jogo ao tocar a parte inferior do canvas
Reinício do jogo com reset de variáveis
📈 Resultados
Implementação completa de um jogo funcional em JavaScript
Simulação de física básica (movimento e colisão)
Estruturação eficiente do código utilizando loops e vetores
Aplicação prática de lógica de programação
💡 Insights
Estruturas de repetição reduzem complexidade do código
Vetores permitem gerenciar múltiplos elementos de forma eficiente
Lógica de colisão é essencial para jogos interativos
Controle de estado é fundamental para funcionamento do game
🧠 Conclusão

O projeto permitiu aplicar na prática conceitos fundamentais de lógica de programação, demonstrando como estruturas básicas podem ser utilizadas para construir aplicações interativas. O desenvolvimento do jogo reforça habilidades em JavaScript e resolução de problemas.
